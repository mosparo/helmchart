# Get release information

To learn more about the release, try:

  $ helm -n {{ .Release.Namespace }} status {{ .Release.Name }}
  $ helm -n {{ .Release.Namespace }} get values {{ .Release.Name }}
  $ helm -n {{ .Release.Namespace }} get all {{ .Release.Name }}

# To delete the release

Use helm uninstall command to delete the release. 

  $ helm -n {{ .Release.Namespace }} uninstall {{ .Release.Name }}

Note that some resources may still be in use after a release is deleted. For example, PersistentVolumeClaims are not deleted by default for some storage classes or if some annotations are set.

SETUP
=====
On first run enter those DB credentials:

Host: {{ .Release.Name }}-db
Port: 3306
Db Name: mosparo
User: mosparo
Pass: mosparo_password

Then in [Administration/GeoIP2](https://[REPLACE_WITH_YOUR_URL]/administration/geoip2/), 
enter the API keys of your free [MaxMind account](https://www.maxmind.com/en/account/sign-in)

Note: CRON Jobs are already activated. Ignore the setup in both GeoIP2 and Administration/Cron Jobs.  
See [cron jobs](https://github.com/mosparo/mosparo/blob/master/docker/standard/config/mosparo.cron) for details.
