# Get release information

To learn more about the release, try:

  $ helm -n {{ .Release.Namespace }} status {{ .Release.Name }}
  $ helm -n {{ .Release.Namespace }} get values {{ .Release.Name }}
  $ helm -n {{ .Release.Namespace }} get all {{ .Release.Name }}

# To delete the release

Use helm uninstall command to delete the release. 

  $ helm -n {{ .Release.Namespace }} uninstall {{ .Release.Name }}

Note that some resources may still be in use after a release is deleted. For exemple, PersistentVolumeClaims are not deleted by default for some storage classes or if some annotations are set.

SETUP
=====
On first run enter those db credentials:

Host: {{ .Release.Name }}-db
Port: 3306
Db Name: mosparo
User: mosparo
Pass: mosparo_password

Then in [Administration/GeoIP2](https://captcha.vapolia.eu/administration/geoip2/), 
enter the API keys of your free [maxmind account](https://www.maxmind.com/en/accounts/xxxxx/license-key/create)

Note: CRON Jobs are already activated. Ignore the setup in bith GeoIP2 and Administration/Cron Jobs.  
See [cron jobs](https://github.com/mosparo/mosparo/blob/master/docker/standard/config/mosparo.cron) for details.
